================================================================================
  IMPLÉMENTATION TECHNIQUE
================================================================================

STOCKAGE:
├─ localStorage['columnSizePreference']
│  ├─ Format: String (ex: "0.8", "1.0")
│  ├─ Localité: Navigateur local
│  └─ Avantage: Rapide (synchrone)
│
└─ grist.getOption('columnSize')
   ├─ Format: String (ex: "0.8", "1.0")
   ├─ Localité: Base de données Grist
   └─ Avantage: Persistance globale

FLUX DE CHARGEMENT:
1. localStorage.getItem('columnSizePreference')
   ↓ (si absent)
2. grist.getOption('columnSize')
   ↓ (si absent)
3. '1.0' (défaut)

FLUX DE SAUVEGARDE:
1. changeColumnSize(size) → CSS appliqué
2. localStorage.setItem('columnSizePreference', size)
3. grist.setOption('columnSize', size)

FLUX DE RESTAURATION:
1. localStorage.getItem('columnSizePreference')
2. setColumnSize() → Sélecteur + styles
3. updateFullscreenTable() (si fullscreen)
4. applyVariableColors() (réappliquer couleurs)
